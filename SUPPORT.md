# Support and feedback

We welcome feedback that helps make ASOgenic safer and more useful.

| You need | Best channel |
| --- | --- |
| A reproducible defect | Open a bug report using the repository's issue template. |
| A new workflow, tool, or improvement | Open a feature request using the issue template. |
| A usage question or setup problem | Start a GitHub Discussion when available, or open an issue with the `question` label. |
| A security vulnerability or exposed credential | Follow [SECURITY.md](SECURITY.md); do not create a public issue. |
| A conduct concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact maintainers privately. |

## Helpful reports

Include the ASOgenic version, operating system, Python version, AI client, a
minimal reproduction, expected behavior, actual behavior, and sanitized logs.
Remove App Store Connect IDs if they identify private apps, and always remove
keys, tokens, `.p8` contents, customer data, and private screenshots.
